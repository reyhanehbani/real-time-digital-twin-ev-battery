# Real-Time Digital Twin of a 355-V-Class Li-ion EV Battery Pack

## Overview

This project focuses on the design and implementation of a real-time
Digital Twin for a 355-V-class Li-ion EV battery pack.

The system integrates:

- Battery modeling
- EKF-based state estimation
- C++
- IIoT communication
- MQTT
- Secure industrial HMI
- Web-based monitoring
